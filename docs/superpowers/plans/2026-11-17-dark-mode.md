# Modo escuro automático Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O site Stelqo segue `prefers-color-scheme: dark` com cores do manual, sem mudar nada no modo claro nem nos mocks.

**Architecture:** Variáveis por função em `assets/css/stelqo.css` (claro = valores de hoje; um bloco `@media (prefers-color-scheme: dark)` troca os valores). CSS de cada página troca cores fixas de superfície clara por essas variáveis. Logo do topo vira `<picture>`. Um verificador headless (`scripts/theme-check.py`) prova: claro idêntico ao de antes, escuro legível, mocks intactos.

**Tech Stack:** HTML/CSS estático, sem build. Python 3 stdlib + Chrome headless (`C:/Program Files/Google/Chrome/Application/chrome.exe`) para verificação. Bash para `scripts/check-brand.sh`.

**Spec:** `docs/superpowers/specs/2026-11-17-dark-mode-design.md`

## Global Constraints

- Gatilho só por `@media (prefers-color-scheme: dark)`; nenhum JS, nenhum botão.
- Cores do escuro só da paleta do manual: #0B0E14, #1C2029, #3C4150, #A6A9B3, #CFCDC8, #F8F5F2, #8EA6FF, #0A33FF, #FFFFFF (e rgba de #F8F5F2/#0B0E14 para linhas, véus e sombras).
- Modo claro pixel-idêntico: todo valor de variável no claro é o literal que existe hoje.
- Mocks congelados nos dois modos (lista `MOCKS` abaixo). A *moldura* do Laboratório (`section#laboratorio.dark`) segue a regra das seções `.dark`; só o conteúdo `.pv` é mock. (Corrige a linha "Laboratório (`#laboratorio` …)" da spec — ver Task 1, passo 6.)
- `<meta name="color-scheme" content="light dark">` nas 6 páginas.
- Texto ≥ 4,5:1; texto grande (≥24px, ou ≥18,66px com peso ≥700) ≥ 3:1.
- Nunca enviar o formulário do contato (CRM real): `fetch` e `sendBeacon` bloqueados em toda cópia de teste.
- Commits terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: Verificador `theme-check` + baseline do claro + checagens estáticas

**Files:**
- Create: `scripts/theme-check.py`
- Modify: `scripts/check-brand.sh`

**Interfaces:**
- Produces:
  - `python -I scripts/theme-check.py snapshot OUT.json [PAGE...]` → grava cores computadas no claro; sai 0.
  - `python -I scripts/theme-check.py light BASELINE.json [PAGE...]` → sai 0 se cores computadas no claro == baseline; senão lista `page|width|path|prop: antes → depois` (até 30) e sai 1.
  - `python -I scripts/theme-check.py dark [--scope SEL] [PAGE...]` → sai 0 se todas as regras do escuro passam; senão lista falhas e sai 1.
  - `PAGE` = nome sem `.html` (`index`, `projetos`, `servicos`, `sobre`, `contato`, `clinica-horizonte`); sem PAGE = as 6.

- [ ] **Step 1: Escrever `scripts/theme-check.py`**

Como o `t8.py` da sessão anterior: para cada página × largura (1440×900, 390×844) gera um wrapper HTML com `<iframe srcdoc>` (cópia da página com `<base href="file:///<repo>/">`, `window.fetch=()=>Promise.reject()`, `navigator.sendBeacon=()=>false` e `<style>*,*::before,*::after{animation:none!important;transition:none!important}</style>` no `<head>`), roda Chrome `--headless=new --disable-gpu --hide-scrollbars --virtual-time-budget=5000 --window-size=W,H --user-data-dir=<tmp> --dump-dom` (mais `--force-dark-mode` no modo `dark`), e lê o JSON que o script do wrapper grava em `body[data-res]`. Uma execução do Chrome por vez (pouca memória na máquina).

Coleta por elemento (chave = caminho CSS `tag:nth-child(n)>…`): `color`, `background-color`, `background-image`, `border-top-color`, `border-bottom-color`, `outline-color`, `box-shadow`, `fill`, `stroke`, e `currentSrc` para `img`.

Regras de `dark` (cada falha = uma linha `page@width: regra — detalhe`):
- `matchMedia('(prefers-color-scheme: dark)').matches` é true (senão aborta: emulação quebrada).
- `body` bg = `rgb(11, 14, 20)`.
- Contraste: todo elemento visível fora de `MOCKS` e de `svg`, com nó de texto próprio não vazio e caixa >1px: fundo efetivo = composição dos `background-color` dos ancestrais (html→elemento); se o ancestral mais próximo com fundo tiver `background-image` ≠ none, pula e conta em `skipped`. Cor do texto com alfa é composta sobre o fundo. Exige ≥4,5 (≥3 se grande).
- Todo `.dark` fora de `MOCKS` tem bg `rgb(28, 32, 41)`.
- `.hdr .logo img` `currentSrc` contém `negativa`.
- Mocks: cores computadas dos elementos dentro de `MOCKS` iguais às do mesmo elemento no claro (roda o claro na mesma execução para comparar).
- `scrollWidth - clientWidth == 0`.
- A 390: depois, clica `.burger` e roda a regra de contraste só dentro de `#menu-mobile`.
- `--scope SEL`: regra de contraste e de `.dark` só para elementos dentro de `SEL`.
- Sanidade: cada seletor de `MOCKS` casa com ≥1 elemento em alguma das 6 páginas; senão sai 2.

Imprime ao final `dark: N falhas, M pulados` / `light: N diferenças`.
